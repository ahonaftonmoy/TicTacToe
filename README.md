# TicTacToe
A simple Tic Tac Toe game built in Java using Swing GUI Library

# Features
 * 3x3 game board
 * Player is X
 * Cpu is O (plays random moves)
 * Win detection for rows, columns and diagonals
 * Draw detection
# How to Run
 * Clone the TicTacToeGui.java
 * Compile it and Run
   (PS: TicTacToe.java is the actual code without
    any GUI and can be played in terminal only)
